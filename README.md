# eigenkit

**Build quantum algorithms once. Run them anywhere.**

eigenkit is a Python library by [EigenOrbit](https://eigenorbit.com) for
writing quantum algorithms against one interface and running them on many
quantum backends, from local simulators to cloud hardware.

> **Status:** this `0.0.0` release is a placeholder. The library is under
> active development, and the first functional release is coming soon.
