1"""Registration of the backends. 

2 

3The NumPy reference simulator only needs NumPy, and it is registered when this 

4package is imported, because it is the default and is always available. The 

5other backends, apart from CUDA Quantum, are registered *lazily*: naming one 

6imports nothing, and its software development kit (PyTorch, PennyLane, Qiskit 

7or Braket) is imported only when a circuit first uses that provider. This keeps 

8`import eigenkit` and `import eigenkit.core` free of these large dependencies. 

9 

10`"pennylane"`, `"qiskit"`, `"braket"`, `"router"` and the other optional 

11backends are registered only when their extra is installed. `cudaq` is not 

12registered automatically: once it is installed, register it explicitly: 

13 

14```python 

15from eigenkit import CudaQuantumBackend, register 

16 

17register("cudaq", CudaQuantumBackend()) 

18``` 

19 

20The backend classes and the configuration dataclasses are re-exported lazily 

21through `__getattr__`. For example, `from eigenkit.core import PennyLaneConfig` 

22imports the PennyLane adapter only when the name is accessed.
