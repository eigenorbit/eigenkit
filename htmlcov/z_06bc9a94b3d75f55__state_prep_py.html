1"""The one state-preparation unitary every backend uses. 

2 

3`AmplitudeEncoding` asks for a unitary whose first column is the requested 

4state, so that `U|0...0> = |amps>`. That leaves the remaining `2**k - 1` 

5columns free, and any orthonormal completion satisfies the request — from 

6`|0...0>`. 

7 

8It stops being free the moment the target register is in any other state. 

9Completions chosen independently — a QR factorisation, a modified 

10Gram-Schmidt over the computational basis, or an SDK's own state-preparation 

11synthesis — agree from `|0...0>` and disagree everywhere else, so the same 

12circuit would return a different value on each backend, with nothing raising. 

13 

14So the completion is fixed here, once, and every backend applies this matrix 

15as an ordinary unitary rather than calling its SDK's state-preparation 

16primitive. The cost is that the SDKs' native state-prep synthesis is unused 

17for this gate; the gain is that a `CircuitSpec` means the same thing 

18everywhere, which is the contract the whole provider layer rests on. 

19""" 

20 

21from __future__ import annotations 

22 

23import numpy as np 

24 

25 

26def state_prep_unitary(amps) -> np.ndarray: 

27 r"""Return the canonical unitary `U` with `U|0...0> = |amps>`. 

28 

29 The first column is `amps`, normalized. The rest are the completion from 

30 a QR factorisation of the identity with `amps` substituted into column 0, 

31 with each column rescaled by the phase of its `R` diagonal so that column 

32 0 comes back exactly `amps` rather than `amps` up to a phase. 

33 

34 Args: 

35 amps (np.ndarray | Sequence[complex]): The state to prepare, as a flat 

36 array-like of length `2**k`. Normalized here if it is not already. 

37 

38 Returns: 

39 The `2**k` x `2**k` unitary, `complex128`. 

40 

41 Raises: 

42 ValueError: If `amps` is all-zero, which names no state. 

43 """ 

44 psi = np.asarray(amps, dtype=np.complex128).reshape(-1) 

45 norm = np.linalg.norm(psi) 

46 if norm == 0.0: # pragma: no cover - the AmplitudeEncoding block rejects this 

47 raise ValueError("AmplitudeEncoding state is all-zero") 

48 psi = psi / norm 

49 seed = np.eye(psi.shape[0], dtype=np.complex128) 

50 seed[:, 0] = psi 

51 q, r = np.linalg.qr(seed) 

52 phases = np.diagonal(r).copy() 

53 phases[phases == 0.0] = 1.0 

54 return q * (phases / np.abs(phases))
