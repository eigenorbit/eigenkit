1"""The Qiskit Runtime backend, for IBM Quantum hardware. 

2 

3Qiskit and qiskit-ibm-runtime are optional dependencies 

4(`pip install eigenkit[qiskit]`). They are imported only when they are needed, so 

5the rest of the library works without them. If Qiskit is missing, `compile()` 

6raises a clear `ImportError`. If qiskit-ibm-runtime is missing, the same kind of 

7error comes when it is first needed: when `compile()` looks up a backend by name, 

8or when the first job is submitted. 

9 

10The backend runs on real IBM backends (Heron devices such as `ibm_fez`, 

11`ibm_marrakesh` and `ibm_torino`), on the device that `service.least_busy()` 

12chooses (`backend_name="least_busy"`), and, for local testing, on the fake backends 

13with noise models from `qiskit_ibm_runtime.fake_provider` and on 

14`qiskit_aer.AerSimulator`. 

15 

16`QiskitRuntimeConfig(primitive=...)` chooses one of two primitives: 

17 

18- `"estimator"`, the default, computes the expectation values of Pauli sums with 

19 `EstimatorV2`, which does the basis rotation and the averaging on the server. 

20 Each observable is one Primitive Unified Bloc (PUB) of a single job, and only 

21 the numbers come back. 

22- `"sampler"` computes the same expectation values from raw histograms of 

23 bitstrings with `SamplerV2`. The Pauli terms of the observables are sorted into 

24 qubit-wise commuting measurement groups, one circuit is run for each group, and 

25 the counts are reduced locally (see the `_sampling` module). There is one PUB 

26 per *group* instead of one per observable, and the shot budget is explicit. 

27 This is what you want when the shot cost of a result is itself what you 

28 measure. 

29 

30`sample()` and `probabilities()` always use `SamplerV2`, whatever the configured 

31primitive, because they are sampling operations and `EstimatorV2` returns no 

32bitstrings. `primitive` only chooses how the expectation values are computed. 

33 

34`submit()` runs `run`, `sample` or `probabilities` without blocking (see 

35`QiskitRuntimeCompiled.submit_methods`), and it can tag the IBM job so that you 

36can find it again. `attach()` rebuilds a handle from the id of a job submitted 

37earlier, for example after the process that submitted it restarted. The 

38`result()` of either handle returns what the blocking method of the same name 

39returns. 

40 

41`zero_state_probability()` and its batched form `zero_state_probabilities()` are 

42used by quantum kernels. They run one `SamplerV2` job, measured in the `Z` basis, 

43for the whole batch. They are not `submit()` methods: 

44`submit_zero_state_probabilities()` submits the batch without blocking, and 

45`retrieve_zero_state_probabilities()` attaches to it again by its job id. 

46 

47The credentials are looked up in this order, and the most explicit one wins: 

48 

491. `QiskitRuntimeConfig(token=..., channel=..., instance=...)`. 

502. The environment variable `QISKIT_IBM_TOKEN`. 

513. The saved account (`~/.qiskit/qiskit-ibm.json`). 

52 

53The channel defaults to `"ibm_quantum_platform"`. The legacy `"ibm_quantum"` 

54channel was retired with the old IBM Quantum Platform, and `QiskitRuntimeService` 

55no longer accepts it at all. 

56 

57For testing, pass a `FakeBackendV2` instance directly as `backend_instance`. No 

58token or service is needed. 

59 

60By default, `gradient_method = "none"`, because runs on a quantum processing unit 

61(QPU) are too expensive for parameter-shift gradients: one backward step costs 

62at least `2 * n_weights` jobs, each with the full shot count. The PyTorch wrapper 

63raises a clear error on `.backward()`. Train on a simulator first, then use the 

64trained weights on the QPU. `enable_gradients=True` in the configuration turns on 

65parameter-shift gradients on the device, and compiling for a paid device then 

66gives a `CostWarning` that states the cost of one backward pass. 

67 

68`compile()` runs `qiskit.transpile(circuit, backend=target, 

69optimization_level=N)` once and caches the transpiled circuit. For the estimator, 

70it also caches the `SparsePauliOp` operators, mapped to the layout of the 

71transpiled circuit. The sampler transpiles each measured circuit on its first use 

72and caches it too. Each `run()` or `submit()` then only binds the parameter values 

73in the PUBs that it passes to the primitive. 

74 

75Example: 

76 ```python 

77 from eigenkit import Circuit, Encoding, Variational, all_z, register 

78 from eigenkit.configs import QiskitRuntimeConfig 

79 

80 blocks = [Encoding(in_features=4), Variational(depth=2)] 

81 

82 # by a registered name (this backend is opt-in, so register it first) 

83 register("qiskit-runtime", QiskitRuntimeConfig(backend_name="ibm_fez")) 

84 circuit = Circuit(blocks=blocks, observables=all_z(4), provider="qiskit-runtime") 

85 

86 # or with the configuration, when a device setting matters 

87 circuit = Circuit( 

88 blocks=blocks, 

89 observables=all_z(4), 

90 provider=QiskitRuntimeConfig(backend_name="ibm_fez"), 

91 ) 

92 ``` 

93 

94 It is opt-in, and it costs money. The first compile for a paid device gives a 

95 `CostWarning`, and `dry_run_info()` reports the shape of a run, including how 

96 many circuits a call runs, before you submit it. 

97"""

175def _validate_job_tags(tags: Mapping[str, str] | None) -> list[str] | None: 

176 """Check `tags` against the IBM job-tag limits and return them as IBM 

177 job tags, `"key=value"` sorted by key; `None` when there are none.""" 

178 if not tags: 

179 return None 

180 if len(tags) > _MAX_JOB_TAGS: 

181 raise ValueError( 

182 f"at most {_MAX_JOB_TAGS} job tags are allowed, got {len(tags)}." 

183 ) 

184 job_tags = [] 

185 for key in sorted(tags, key=str): 

186 value = tags[key] 

187 if not isinstance(key, str) or not isinstance(value, str): 

188 raise ValueError( 

189 f"job tag keys and values must be str, got {key!r}: {value!r}." 

190 ) 

191 if not key or not value: 

192 raise ValueError( 

193 f"job tag keys and values must be non-empty, got {key!r}: {value!r}." 

194 ) 

195 if "=" in key: 

196 raise ValueError( 

197 f"job tag key {key!r} contains '=', which separates key from value." 

198 ) 

199 entry = f"{key}={value}" 

200 if len(entry) > _MAX_JOB_TAG_LENGTH: 

201 raise ValueError( 

202 f"job tag {key!r} is {len(entry)} characters as key=value; IBM allows " 

203 f"at most {_MAX_JOB_TAG_LENGTH}." 

204 ) 

205 job_tags.append(entry) 

206 return job_tags

221class QiskitRuntimeConfig(SecretFieldsMixin): 

222 """Device configuration for the Qiskit Runtime backend. 

223 

224 There are two ways to choose the target backend: 

225 

226 - `backend_name` is looked up with `QiskitRuntimeService`. It needs 

227 credentials: a token, an environment variable or a saved account. 

228 - `backend_instance` is a `BackendV2` that is used directly. It is useful for 

229 tests with a fake backend, or to pass any backend that is already 

230 configured. 

231 

232 Args: 

233 backend_name: The IBM backend name, for example `"ibm_fez"`, or 

234 `"least_busy"` for the least busy operational device that the account 

235 can use, chosen once per compiled circuit. It is required unless 

236 `backend_instance` is set, and it is ignored when it is. Default: 

237 `None`. 

238 backend_instance: A backend that is already configured. It takes 

239 precedence over `backend_name`. Default: `None`. 

240 shots: The number of shots per circuit run. Default: `1024`. 

241 optimization_level: The optimisation level passed to `qiskit.transpile`, 

242 from `0` to `3`. Default: `1`. 

243 seed_transpiler: The seed of the random passes of the transpiler, mainly 

244 the `SabreLayout` and `SabreSwap` passes, which choose the layout and 

245 the routing. `None`, the default, draws a new seed for every compile, 

246 so a circuit that needs routing compiles to a different number of 

247 gates on every run. Within one compile, all the transpilations share 

248 the seed, including the shifted copies that a gradient on hardware 

249 compiles. Set it whenever two compilations must be comparable. Since 

250 compiling submits nothing, trying a few seeds and keeping the cheapest 

251 circuit is a cheap and fair way to choose a layout. 

252 primitive: The Runtime primitive that computes the expectation values. 

253 `"estimator"`, the default, uses `EstimatorV2`, with one Primitive 

254 Unified Bloc (PUB) per observable in each job. `"sampler"` uses 

255 `SamplerV2`, with one PUB per qubit-wise commuting measurement group, 

256 and reduces the raw counts locally. `sample()` and `probabilities()` 

257 use `SamplerV2` with either value. 

258 group_commuting: Whether the sampler puts qubit-wise commuting Pauli terms 

259 into shared measurement circuits. `False` runs one circuit per term, 

260 which runs more circuits but keeps the shot budget of each term 

261 independent. The estimator ignores it. Default: `True`. 

262 token: The token passed to `QiskitRuntimeService` when `backend_instance` 

263 is `None`. With `None`, the backend uses `QISKIT_IBM_TOKEN`, then the 

264 saved account file. It is secret: it is never shown by `repr()`, and it 

265 is never saved in `.eigenkit` bundles, pickles or joblib checkpoints. 

266 After a load it is `None`, so set `QISKIT_IBM_TOKEN`. 

267 channel: The service channel: `"ibm_quantum_platform"` (the default), 

268 `"ibm_cloud"` or `"local"`. The legacy `"ibm_quantum"` channel was 

269 retired, and `QiskitRuntimeService` no longer accepts it. 

270 instance: The service instance, as a Cloud Resource Name (CRN) or a name, 

271 when one applies. Default: `None`. 

272 service_kwargs: Extra keyword arguments passed to `QiskitRuntimeService`, 

273 such as `region`, `url` or `proxies`. 

274 poll_timeout_seconds: How long `result()` waits before it gives up, in 

275 seconds. Default: `3600`. 

276 enable_gradients: Whether to allow parameter-shift gradients on the 

277 device: PyTorch `.backward()`, `jacobian()` and gradient-based 

278 optimisers. It is off by default, because one backward pass costs 

279 at least `2 * n_weights` times the jobs of a forward call. When it is on, 

280 compiling for a paid device gives a `CostWarning` that states this 

281 cost. 

282 primitive_options: Options applied to every `SamplerV2` and `EstimatorV2` 

283 that the backend builds, through `options.update(**primitive_options)`, 

284 for example 

285 `{"dynamical_decoupling": {"enable": True, "sequence_type": "XpXm"}}` 

286 or `{"twirling": {"enable_gates": True}}`. Nested dictionaries merge 

287 into the primitive's defaults. Qiskit Runtime validates the names and 

288 values when the primitive is built, before anything is submitted, so 

289 an option that the primitive in use does not know raises there: 

290 `sample()` and `probabilities()` always use `SamplerV2`, which has no 

291 `resilience_level`. `shots` and the job tags are set after these 

292 options, so they cannot be changed here. With twirling, Qiskit Runtime 

293 runs `num_randomizations * shots_per_randomization` shots, rounding 

294 up when one of them is `"auto"`, which can be more than `shots`. The 

295 default, `{}`, applies nothing. 

296 """

526 `QiskitRuntimeCompiled.probabilities()` returns. 

527

532 `"probabilities"`, if the circuit has more than 

533 `_sampling.MAX_DENSE_QUBITS` (`24`) qubits.

537 return self._expectation_values(primitive_result)

1190 """Evaluate the circuit and return one expectation value per observable. 

1191

1193 when `weights` and `inputs` are both 1-D, and `(B, n_obs)` otherwise. 

1194 

1195 Args:

1197 or a 2-D array with a leading batch axis. 

1198 inputs (np.ndarray): The input features, with the same 1-D or 2-D 

1199 shapes as `weights`. 

1200 

1201 Returns: 

1202 One expectation value per observable. 

1203 """ 

1204 weights = np.asarray(weights, dtype=np.float64) 

1205 inputs = np.asarray(inputs, dtype=np.float64) 

1206 sampling = self._config.primitive == "sampler" 

1207 if weights.ndim == 1 and inputs.ndim == 2: 

1208 return ( 

1209 self._run_sampler_broadcast(weights, inputs) 

1210 if sampling 

1211 else self._run_broadcast(weights, inputs) 

1212 ) 

1213 # `_run_one` goes through `submit`, which already routes to whichever 

1214 # primitive the config names, so the per-sample loop is shared. 

1215 return batch_call(self._run_one, weights, inputs)

1220 def _run_broadcast(self, weights: np.ndarray, inputs: np.ndarray) -> np.ndarray: 

1221 """Native batched evaluation via EstimatorV2 parameter broadcasting. 

1222 

1223 EstimatorV2 PUBs accept a `(B, n_params)` array — the primitive 

1224 evaluates all B parameter assignments inside one job per 

1225 observable, so we go from `B * n_obs` jobs down to `n_obs`. 

1226 """ 

1227 param_array = self._param_values_batched(weights, inputs) 

1228 pubs = [(self._transpiled_circuit, op, param_array) for op in self._operators] 

1229 primitive_result = job_result( 

1230 self._estimator().run(pubs), self._config.poll_timeout_seconds 

1231 ) 

1232 output = np.stack( 

1233 [ 

1234 np.asarray(primitive_result[k].data.evs, dtype=np.float64).reshape(-1) 

1235 for k in range(self._n_observables) 

1236 ] 

1237 ) 

1238 # Stack is (n_obs, B); contract is (B, n_obs). 

1239 return output.T

1241 def _param_values_batched( 

1242 self, weights: np.ndarray, inputs: np.ndarray, param_order=None 

1243 ) -> np.ndarray: 

1244 """Build a `(B, n_params)` array in transpiled-circuit parameter order. 

1245 

1246 Weight columns are broadcast across all B rows (shared across 

1247 the batch); input columns vary per row. `param_order` defaults to the 

1248 bare circuit's — the sampler path passes the measured circuit's. 

1249 """ 

1250 batch_size = inputs.shape[0] 

1251 order = self._param_order if param_order is None else param_order 

1252 n_params = len(order) 

1253 arr = np.empty((batch_size, n_params), dtype=np.float64) 

1254 for col, symbol in enumerate(order): 

1255 name = symbol.name 

1256 if name.startswith("w"): 

1257 arr[:, col] = float(weights[int(name[1:])]) 

1258 elif name.startswith("x"): 1258 ↛ 1261line 1258 didn't jump to line 1261 because the condition on line 1258 was always true

1259 arr[:, col] = inputs[:, int(name[1:])] 

1260 else: 

1261 raise RuntimeError(

1263 ) 

1264 return arr

1266 def submit( 

1267 self, 

1268 weights: np.ndarray, 

1269 inputs: np.ndarray, 

1270 *, 

1271 method: str = "run", 

1272 tags: Mapping[str, str] | None = None, 

1273 ) -> QiskitRuntimeJobHandle: 

1274 """Submit the circuit without blocking, and return a job handle. 

1275 

1276 Nothing blocks: `handle.result()` waits for the job and decodes it in the 

1277 same way as the blocking method of the same name. For `"run"`, the handle 

1278 returns expectation values with either primitive: the counts of the 

1279 sampler are reduced when the result is collected, so the two paths look 

1280 the same to the caller. `"sample"` and `"probabilities"` are always one 

1281 `SamplerV2` job measured in the `Z` basis, whatever the configured 

1282 primitive. 

1283 

1284 Args: 

1285 weights (np.ndarray): The parameter vector for one sample (1-D). 

1286 inputs (np.ndarray): The input features for one sample (1-D). 

1287 method (str): What the job computes, one of `submit_methods`. 

1288 `"run"`, the default, measures the observables, like `run()`. 

1289 `"sample"` returns the measurement histogram, like `sample()`. 

1290 `"probabilities"` returns the distribution over every basis state, 

1291 like `probabilities()`. 

1292 tags (Mapping[str, str] | None): Tags to put on the IBM job, so that 

1293 you can find it again later with 

1294 `QiskitRuntimeService.jobs(job_tags=[...])`. Each one becomes the 

1295 job tag `"key=value"`, sorted by key. IBM allows at most 8 tags of 

1296 at most 86 characters each. Keys and values must not be empty, and 

1297 a key must not contain `=`. 

1298 

1299 Returns: 

1300 handle (JobHandle): A handle for the submitted job. 

1301 

1302 Raises: 

1303 ValueError: If `method` is not in `submit_methods`, if `weights` or 

1304 `inputs` is not 1-D, or if `tags` breaks the IBM job tag limits. 

1305 In all these cases, no primitive is built and nothing is 

1306 submitted. 

1307 """ 

1308 _check_submit_method(method) 

1309 _check_one_sample("submit", weights, inputs) 

1310 job_tags = _validate_job_tags(tags) 

1311 weights = np.asarray(weights, dtype=np.float64) 

1312 inputs = np.asarray(inputs, dtype=np.float64) 

1313 if method != "run": 

1314 pubs = self._z_basis_pubs(weights, inputs) 

1315 primitive = self._sampler() 

1316 elif self._config.primitive == "sampler": 

1317 bases = [group.basis for group in self._groups] 

1318 pubs = self._sampler_pubs(bases, weights, inputs) 

1319 primitive = self._sampler() 

1320 else: 

1321 pubs = self._build_pubs(weights, inputs) 

1322 primitive = self._estimator() 

1323 if job_tags: 

1324 primitive.options.environment.job_tags = job_tags 

1325 return self._handle(primitive.run(pubs), method)
