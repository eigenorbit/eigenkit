1"""Hamiltonian-simulation helpers for the honest (hardware-faithful) HHL path. 

2 

3The reference HHL path applies ``e^{iAt}`` as a dense ``QubitUnitary`` from 

4``scipy.linalg.expm`` — cheap to simulate, impossible to synthesise on hardware. The 

5honest path instead writes the Hermitian ``A`` as a sum of Pauli strings 

6``A = Σ_k c_k P_k`` so that ``e^{iAt}`` can be Trotterised into elementary gates (see 

7[`TrotterBlock`][eigenkit.core.blocks.TrotterBlock]). 

8 

9The term count is the honest cost metric, and it follows sparsity **in the Pauli 

10basis**, which is not sparsity of the matrix: a non-zero at ``(i, j)`` feeds the strings 

11whose X/Y support is ``i XOR j``, so the count tracks the number of *distinct* offsets. 

12A band has only the ``log2 N`` patterns ``2^k − 1``; a scattered pattern exhausts them, 

13and a random diagonal still needs ``N`` because the Z-string coefficients are the 

14Walsh–Hadamard transform of the diagonal. So "sparse ⇒ few terms" is false; 

15"constructed as a short Pauli sum ⇒ few terms" is what holds. HHL 2009's premise is a 

16different input model (``s``-sparse, row-computable, via a sparse-access oracle) whose 

17cost analysis does not transfer here. 

18""" 

19

27# Single-qubit Pauli matrices, keyed by the symbol used in a Pauli string. 

28_PAULI_MATRICES: dict[str, np.ndarray] = { 

29 "I": np.array([[1, 0], [0, 1]], dtype=complex), 

30 "X": np.array([[0, 1], [1, 0]], dtype=complex), 

31 "Y": np.array([[0, -1j], [1j, 0]], dtype=complex), 

32 "Z": np.array([[1, 0], [0, -1]], dtype=complex), 

33}

36def pauli_string_matrix(pauli_string: str) -> np.ndarray: 

37 """Dense matrix of a Pauli string. 

38 

39 ``pauli_string[i]`` acts on qubit ``i``; the operator is the Kronecker product in qubit 

40 order, qubit 0 being the most significant factor (the library's big-endian layout). 

41 

42 Args: 

43 pauli_string: Non-empty string over ``{I, X, Y, Z}``. 

44 

45 Returns: 

46 A ``2^n × 2^n`` complex matrix, ``n = len(pauli_string)``. 

47 """ 

48 if not pauli_string: 

49 raise ValueError("pauli_string must be non-empty") 

50 matrix = np.array([[1.0 + 0j]]) 

51 for symbol in pauli_string: 

52 try: 

53 factor = _PAULI_MATRICES[symbol] 

54 except KeyError: 

55 raise ValueError( 

56 f"invalid Pauli symbol {symbol!r}; expected one of I, X, Y, Z" 

57 ) from None 

58 matrix = np.kron(matrix, factor) 

59 return matrix

62def pauli_decompose(A: np.ndarray, rtol: float = 1e-10) -> list[tuple[complex, str]]: 

63 """Decompose a Hermitian matrix into a weighted sum of Pauli strings. 

64 

65 The ``4^n`` Pauli strings are orthogonal under the Hilbert–Schmidt product 

66 (``Tr(P_k P_l) = 2^n δ_kl``), so ``c_k = Tr(P_k A) / 2^n``. For Hermitian ``A`` every 

67 ``c_k`` is real up to numerical noise; the imaginary part is returned so callers can 

68 assert it is negligible. 

69 

70 Pruning is **relative** to ``max|A_ij|``, so the term list — and every circuit built 

71 from it — is invariant under ``A → αA``. An absolute threshold would make the honest 

72 path depend on the physical units of ``A``. 

73 

74 Args: 

75 A: A Hermitian ``2^n × 2^n`` matrix (array-like). 

76 rtol: Relative pruning tolerance; terms with ``|c_k| <= rtol · max|A_ij|`` go. 

77 

78 Returns: 

79 ``(coeff, pauli_string)`` pairs in lexicographic order over ``I < X < Y < Z``. 

80 

81 !!! warning 

82 The *order* of this list is part of the numerical contract of 

83 [`TrotterBlock`][eigenkit.core.blocks.TrotterBlock]: the first-order Trotter 

84 error depends on the order the factors are applied in, so reordering these 

85 terms changes honest-mode results at a fixed ``trotter_steps``. Pinned by a 

86 regression test; do not change it casually. 

87 

88 Raises: 

89 ValueError: If ``A`` is not a square 2-D matrix, its dimension is not a power of 

90 two, or it is not Hermitian to within ``1e-8`` relative to its scale. 

91 """ 

92 A = np.asarray(A, dtype=complex) 

93 if A.ndim != 2 or A.shape[0] != A.shape[1]: 

94 raise ValueError(f"A must be a square matrix, got shape {A.shape}") 

95 dim = int(A.shape[0]) 

96 if dim < 1 or (dim & (dim - 1)) != 0: 

97 raise ValueError(f"A dimension must be a power of two, got {dim}") 

98 n_qubits = dim.bit_length() - 1 

99 scale = float(np.max(np.abs(A))) 

100 # Relative to the matrix, with no floor under it. A floor such as `max(scale, 1.0)` 

101 # would hold the tolerance at 1e-8 however small A is, so every matrix with entries 

102 # at or below that would pass whatever its structure — `1e-9 * [[0, 1], [0, 0]]` 

103 # among them — and `TrotterBlock` would drop the imaginary parts and evolve 

104 # something else. An all-zero A still passes: `atol=0` with `rtol=0` compares 

105 # exactly, and it is equal to its own conjugate transpose. 

106 if not np.allclose(A, A.conj().T, atol=1e-8 * scale, rtol=0): 

107 raise ValueError( 

108 "A is not Hermitian; pauli_decompose expects a Hermitian operator " 

109 "(the honest HHL path only simulates Hermitian A)." 

110 ) 

111 threshold = rtol * scale 

112 

113 coefficients = _pauli_coefficients(A) 

114 

115 terms: list[tuple[complex, str]] = [] 

116 for symbols in itertools.product("IXYZ", repeat=n_qubits): 

117 pauli_string = "".join(symbols) 

118 x_mask, z_mask = _string_masks(pauli_string) 

119 coeff = complex(coefficients[x_mask, z_mask]) 

120 if abs(coeff) > threshold: 

121 terms.append((coeff, pauli_string)) 

122 return terms

125def _string_masks(pauli_string: str) -> tuple[int, int]: 

126 """``(x, z)`` bit masks of a Pauli string in the library's big-endian layout. 

127 

128 ``x`` marks the qubits carrying X or Y, ``z`` those carrying Z or Y. Qubit 0 is the 

129 most significant Kronecker factor, matching `pauli_string_matrix()`, so it owns bit 

130 ``n−1``, which is the layout `_pauli_coefficients()` indexes its table by. 

131 """ 

132 n = len(pauli_string) 

133 x_mask = z_mask = 0 

134 for k, symbol in enumerate(pauli_string): 

135 bit = 1 << (n - 1 - k) 

136 if symbol in ("X", "Y"): 

137 x_mask |= bit 

138 if symbol in ("Z", "Y"): 

139 z_mask |= bit 

140 return x_mask, z_mask

143def _walsh_hadamard(values: np.ndarray) -> np.ndarray: 

144 """Unnormalised Walsh–Hadamard transform along the last axis. 

145 

146 ``out[..., z] = Σ_r (−1)^popcount(r & z) · values[..., r]``, in 

147 ``O(N log N)`` per row instead of ``O(N²)``. 

148 """ 

149 out = np.array(values, dtype=complex, copy=True) 

150 length = out.shape[-1] 

151 step = 1 

152 while step < length: 

153 out = out.reshape(*out.shape[:-1], length // (2 * step), 2, step) 

154 lower, upper = out[..., 0, :].copy(), out[..., 1, :].copy() 

155 out[..., 0, :] = lower + upper 

156 out[..., 1, :] = lower - upper 

157 out = out.reshape(*out.shape[:-3], length) 

158 step *= 2 

159 return out

162def _pauli_coefficients(A: np.ndarray) -> np.ndarray: 

163 """All ``4^n`` Pauli coefficients of ``A`` as a table indexed by ``[x, z]``. 

164 

165 A Pauli string has exactly **one** non-zero per row — at column ``r ⊕ x``, with value 

166 ``(−i)^{n_Y} · (−1)^{popcount(r & z)}`` where ``n_Y = popcount(x & z)``. So the 

167 Hilbert–Schmidt trace collapses to a single sum over rows:: 

168 

169 Tr(P·A) = (−i)^{n_Y} · Σ_r (−1)^{popcount(r & z)} · A[r ⊕ x, r] 

170 

171 and that sum, taken over *all* ``z`` at once for a fixed ``x``, is a Walsh–Hadamard 

172 transform of the ``x``-shifted diagonal of ``A``. The table therefore costs 

173 ``O(N² log N)``, against the ``O(N⁴)`` of forming each of the ``4^n`` dense Pauli 

174 matrices and contracting it, which is what bounds the reachable system size. 

175 """ 

176 dim = int(A.shape[0]) 

177 rows = np.arange(dim) 

178 # shifted[x, r] = A[r ⊕ x, r] — the diagonal of A displaced by x. 

179 shifted = A[rows[None, :] ^ rows[:, None], rows[None, :]] 

180 table = _walsh_hadamard(shifted) 

181 # The (−i)^{n_Y} phase, with n_Y = popcount(x & z) over the table's own indices. 

182 n_y = np.bitwise_count(rows[:, None] & rows[None, :]) 

183 table *= np.power(-1j, n_y) 

184 return table / dim

187def _symplectic_bits( 

188 pauli_strings: list[str], 

189) -> tuple[np.ndarray, np.ndarray]: 

190 """Pack Pauli strings into ``(x, z)`` bitmasks, one ``uint64`` per string. 

191 

192 ``X → (1, 0)``, ``Z → (0, 1)``, ``Y → (1, 1)``, ``I → (0, 0)``. Two strings commute 

193 iff ``popcount(x_P & z_Q) + popcount(x_Q & z_P)`` is even — the symplectic form. 

194 """ 

195 n = len(pauli_strings[0]) if pauli_strings else 0 

196 if any(len(s) != n for s in pauli_strings): 

197 raise ValueError( 

198 "all Pauli strings must have the same length; a ragged list would be " 

199 "packed into one bit layout and silently yield wrong commutation parities" 

200 ) 

201 if n > 64: 

202 raise ValueError(f"Pauli strings longer than 64 qubits are unsupported (got {n})") 

203 x_bits = np.zeros(len(pauli_strings), dtype=np.uint64) 

204 z_bits = np.zeros(len(pauli_strings), dtype=np.uint64) 

205 for i, s in enumerate(pauli_strings): 

206 x = z = 0 

207 for q, ch in enumerate(s): 

208 bit = 1 << q 

209 if ch in ("X", "Y"): 

210 x |= bit 

211 if ch in ("Z", "Y"): 

212 z |= bit 

213 x_bits[i] = np.uint64(x) 

214 z_bits[i] = np.uint64(z) 

215 return x_bits, z_bits

218def anticommuting_weight_profile( 

219 pauli_terms: list[tuple[complex, str]] | tuple[tuple[float, str], ...], 

220) -> np.ndarray: 

221 """Per-term anticommuting suffix weights ``R_k`` of a Pauli sum. 

222 

223 Returns ``R_k = |c_k| · Σ_{l > k, P_l anticommutes with P_k} |c_l|``, indexed in the 

224 order ``pauli_terms`` is given — the order 

225 [`TrotterBlock`][eigenkit.core.blocks.TrotterBlock] applies the factors in. Two 

226 Pauli strings either commute or anticommute, and in the latter case 

227 ``‖[P_k, P_l]‖ = 2`` exactly, so ``R`` carries all the spectral information the leading 

228 Trotter bounds need: ``‖[Σ_{l>k} c_l P_l, c_k P_k]‖ ≤ 2 R_k``. 

229 

230 Costs ``O(L² n / 64)`` word operations, negligible beside the decomposition that 

231 produced the terms. 

232 """ 

233 coeffs = np.array([abs(complex(c)) for c, _ in pauli_terms], dtype=float) 

234 strings = [s for _, s in pauli_terms] 

235 n_terms = len(strings) 

236 if n_terms == 0: 

237 return np.zeros(0, dtype=float) 

238 x_bits, z_bits = _symplectic_bits(strings) 

239 

240 result = np.zeros(n_terms, dtype=float) 

241 block = max(1, min(n_terms, 4_194_304 // max(n_terms, 1))) 

242 index = np.arange(n_terms) 

243 for start in range(0, n_terms, block): 

244 stop = min(start + block, n_terms) 

245 xk = x_bits[start:stop, None] 

246 zk = z_bits[start:stop, None] 

247 parity = np.bitwise_count(xk & z_bits[None, :]) + np.bitwise_count( 

248 x_bits[None, :] & zk 

249 ) 

250 anticommutes = (parity & 1).astype(bool) 

251 # Keep only the strict upper triangle l > k. 

252 anticommutes &= index[None, :] > index[start:stop, None] 

253 result[start:stop] = coeffs[start:stop] * (anticommutes * coeffs[None, :]).sum( 

254 axis=1 

255 ) 

256 return result

259def trotter_drift_bound( 

260 pauli_terms: list[tuple[complex, str]] | tuple[tuple[float, str], ...], 

261 tau: float, 

262 order: int, 

263) -> float: 

264 """Upper bound on ``‖A_eff − A‖`` for one Trotter step of size ``tau``. 

265 

266 Because the honest path holds ``tau`` fixed across every controlled power, QPE is 

267 *exact* phase estimation of the single step unitary ``W``, and the whole circuit is 

268 ideal HHL for the effective generator ``A_eff := Log(W)/(i·tau)``. The entire Trotter 

269 error is that one spectral substitution, and this bounds its size. 

270 

271 Both are leading-order product-formula bounds, of the commutator-scaling form 

272 Theorem 11 of Childs, Su, Tran, Wiebe and Zhu establishes (*Theory of Trotter Error 

273 with Commutator Scaling*, Phys. Rev. X 11, 011020, 2021; preprint arXiv:1912.08854). 

274 That theorem is stated up to an order of magnitude, so the constants below are not 

275 taken from it. Written here for Pauli terms, where ``‖[P_k, P_l]‖ ∈ {0, 2}``: 

276 

277 * ``order = 1``: ``τ · Γ₁``, ``Γ₁ = Σ_k R_k = Σ_{k<l, anticommuting} |c_k c_l|``. 

278 * ``order = 2``: ``τ² · Γ₂``, ``Γ₂ = ⅓ Σ_k S_k R_k + ⅙ Σ_k |c_k| R_k`` with suffix sums 

279 ``S_k = Σ_{l>k} |c_l|``. The symmetric product is a palindrome, so the first-order 

280 commutator cancels and the leading error is ``O(τ²)``. 

281 

282 These bound the *leading* Trotter term. They also bound the full ``‖A_eff − A‖`` up to 

283 the Lipschitz constant of the principal logarithm, which is ~1 in the regime the caller 

284 drives ``tau`` into; outside it the number is an estimate, not a bound. Both the 

285 constants and the upper-bound property are pinned by tests against ``‖A_eff − A‖`` 

286 computed exactly on random Hermitian matrices. 

287 

288 ``Γ₁`` is exactly invariant under permutations of ``pauli_terms`` — reordering flips the 

289 signs of the anticommuting pairs' contributions, never which pairs appear — so no 

290 reordering can improve the guarantee. ``Γ₂`` contains suffix sums and is not invariant, 

291 which is a further reason the term order is pinned. 

292 

293 Args: 

294 pauli_terms: ``(coeff, pauli_string)`` terms in **application order**. 

295 tau: Trotter step size (``time / steps``); only ``|tau|`` matters. 

296 order: 1 (Lie–Trotter) or 2 (symmetric Strang). 

297 

298 Returns: 

299 A non-negative bound, exactly ``0.0`` when all terms mutually commute. 

300 """ 

301 if order not in (1, 2): 

302 raise ValueError(f"order must be 1 or 2, got {order}") 

303 coeffs = np.array([abs(complex(c)) for c, _ in pauli_terms], dtype=float) 

304 if coeffs.size == 0: 

305 return 0.0 

306 R = anticommuting_weight_profile(pauli_terms) 

307 if not R.any(): 

308 return 0.0 

309 tau = abs(float(tau)) 

310 if order == 1: 

311 return float(tau * R.sum()) 

312 # Suffix sums S_k = Σ_{l>k} |c_l|. 

313 S = np.concatenate([np.cumsum(coeffs[::-1])[::-1][1:], [0.0]]) 

314 gamma2 = float((S * R).sum() / 3.0 + (coeffs * R).sum() / 6.0) 

315 return tau * tau * gamma2
