27def _unit_scale(batch: torch.Tensor) -> torch.Tensor: 

28 # Scale each row by a power of two that brings its largest entry into 

29 # [0.5, 1). The scaling is exact, so the angles keep every bit wherever the 

30 # norm neither overflows nor underflows, and stay finite where it would. The 

31 # factor is a constant in two halves, so neither overflows the dtype, and the 

32 # backward pass multiplies by the same powers of two (torch.ldexp would 

33 # build them in float32 there). 

34 largest = batch.detach().abs().amax(dim=-1, keepdim=True) 

35 _, exponent = torch.frexp(largest) 

36 half = exponent // 2 

37 one = torch.ones_like(largest) 

38 return batch * torch.ldexp(one, -half) * torch.ldexp(one, half - exponent)

92def rotate_weight(R: torch.Tensor, W: torch.Tensor, side: Side = "out") -> torch.Tensor: 

93 r"""Rotate the output or the input channels of a weight tensor by an orthogonal 

94 matrix. 

95 

96 The weight is read as the matrix `W.reshape(out, in·k·k)`. Rotating its rows 

97 (`side="out"`, \(RW\)) or its input channels (`side="in"`, 

98 \(W (R^\top \otimes I)\)) keeps 

99 every singular value of that matrix, so the operator norm, and the Lipschitz 

100 constant, of the layer are unchanged. For a convolution `R` acts pixel by 

101 pixel, so the same holds for the convolution operator. 

102 

103 Numerical contract for `side="out"`: 

104 `(R @ W.reshape(W.shape[0], -1)).reshape(W.shape)`, which is `R @ W` for a 2-D 

105 weight. `side="in"` computes 

106 `torch.einsum("oi...,ji->oj...", W, R).contiguous()`, which is `W @ R.T` for a 

107 2-D weight. 

108 

109 Args: 

110 R (torch.Tensor): An orthogonal matrix, `(out, out)` for `side="out"` or 

111 `(in, in)` for `side="in"`. 

112 W (torch.Tensor): A weight `(out, in)` or `(out, in, *kernel)`. 

113 side (Side): `"out"` or `"in"`. Default: `"out"`. 

114 

115 Returns: 

116 torch.Tensor: The rotated weight, of the shape of `W`. 

117 

118 Raises: 

119 ValueError: If `side` is unknown or `R` does not match the axis. 

120 """
