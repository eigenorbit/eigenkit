73class CustomQuantumClassifier(ModelAccessMixin, BaseQuantumClassifier): 

74 """Classifier compatible with scikit-learn, built from your own list of blocks. 

75 

76 Give any sequence of blocks (`Encoding`, `Variational`, `StrongVariational`, 

77 `Reuploading`, or a custom block from `CircuitBuilder.to_block()`) and an 

78 `observables` specification, as for `Circuit`. The estimator connects them 

79 into a quantum layer followed by a classical `nn.Linear` head, and trains the 

80 whole model with the cross-entropy loss. When the number of features of the 

81 data differs from the number of inputs that the circuit expects, an 

82 `nn.Linear` adapter is added in front automatically. 

83 

84 The number of inputs of the circuit is read from the first `Encoding` or 

85 `Reuploading` block, so `blocks` must contain one. A circuit whose inputs 

86 enter through another block, such as the `UnaryLoader` of 

87 `eigenkit.orthogonal`, is not supported yet and raises a `ValueError` in 

88 `fit()`, even with `in_features` given. 

89 

90 Args: 

91 blocks: The list of blocks, in order. 

92 observables: The observables. It takes the same options as 

93 `Circuit(observables=...)`. Default: `None` (`Z` on every qubit). 

94 provider: The backend. Default: `"numpy"`. 

95 in_features: The number of features of the data. If None, it is inferred 

96 from the first `Encoding` or `Reuploading` block. 

97 n_classes: The number of output classes. If None, it is inferred from the 

98 training labels. 

99 lr: The learning rate of the optimiser. 

100 optimizer: The name of the optimiser. The supported names are `"adam"`, 

101 `"adamw"`, `"rmsprop"` and `"sgd"`. 

102 optimizer_kwargs: Extra keyword arguments passed to the optimiser. 

103 epochs: The number of training epochs. 

104 batch_size: The size of each mini-batch. 

105 show_progress: If True, a tqdm progress bar is shown. 

106 random_state: The seed. 

107 

108 Attributes: 

109 train_losses_: The cross-entropy loss of each epoch, set by `fit()`. 

110 validation_losses_: The validation cross-entropy loss of each epoch, set 

111 by `fit()` when validation data is given. 

112 

113 Example: 

114 ```python 

115 import numpy as np 

116 from eigenkit import ( 

117 CustomQuantumClassifier, Encoding, Variational, all_z, 

118 ) 

119 

120 rng = np.random.default_rng(0) 

121 X_train, X_test = rng.uniform(0, np.pi, (20, 4)), rng.uniform(0, np.pi, (5, 4)) 

122 y_train = np.array([0, 1] * 10) 

123 

124 blocks = [ 

125 Encoding(in_features=4, rotation="RY"), 

126 Variational(depth=2, rotation="RY"), 

127 ] 

128 model = CustomQuantumClassifier( 

129 blocks=blocks, observables=all_z(4), epochs=10, 

130 ) 

131 model.fit(X_train, y_train) 

132 predictions = model.predict(X_test) 

133 ``` 

134 """

317 """Regressor compatible with scikit-learn, built from your own list of blocks. 

318 

319 It is the regression counterpart of 

320 [`CustomQuantumClassifier`][eigenkit.torch.estimators.custom.CustomQuantumClassifier]. 

321 It wraps your quantum `Circuit` with an `nn.Linear` head of one neuron, trained 

322 with the chosen regression loss. An `nn.Linear` input adapter is added when the 

323 number of features of the data differs from the number of inputs of the 

324 circuit. 

325 

326 As for the classifier, the number of inputs of the circuit is read from the 

327 first `Encoding` or `Reuploading` block, so `blocks` must contain one; a 

328 `UnaryLoader` is not supported yet and raises a `ValueError` in `fit()`. 

329 

330 Args: 

331 blocks: The list of blocks, in order. 

332 observables: The observables. It takes the same options as 

333 `Circuit(observables=...)`. 

334 provider: The backend. Default: `"numpy"`. 

335 in_features: The number of features of the data. If None, it is inferred 

336 from the first `Encoding` or `Reuploading` block. 

337 lr: The learning rate of the optimiser. 

338 optimizer: The name of the optimiser: `"adam"`, `"adamw"`, `"rmsprop"` or 

339 `"sgd"`. 

340 optimizer_kwargs: Extra keyword arguments passed to the optimiser. 

341 epochs: The number of training epochs. 

342 batch_size: The size of each mini-batch. 

343 loss_func: The regression loss: `"mse"`, `"mae"` or `"huber"`. 

344 huber_delta: The threshold of the Huber loss. 

345 huber_reduction: The reduction of the Huber loss: `"mean"` or `"sum"`. 

346 show_progress: If True, a tqdm progress bar is shown. 

347 random_state: The seed. 

348 

349 Attributes: 

350 train_losses_: The training loss of each epoch, set by `fit()`.
